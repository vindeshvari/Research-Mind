# Multi-Agent AI System

An interactive multi-agent research and assistant system powered by **LangChain**, **Groq API**, **Tavily Search**, and hosted on **Streamlit**.

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://multi-agent-system-research.streamlit.app/)

---

## Features
- **Multi-Agent Collaboration:** Integrates specialized agents to handle complex reasoning, search retrieval, and synthesis tasks.
- **Fast Inference:** Powered by Groq's high-speed LLMs for near-instant responses.
- **Web Research Integration:** Utilizes Tavily Search for real-time data gathering.
- **Interactive Web UI:** Built with Streamlit for a seamless user experience.
